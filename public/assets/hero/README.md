# Hero Visual Assets Folder

Place your hero section assets in this directory.

### Recommended Files:
- `hero-collage.png` - Full composite collage image (default fallback uses the attached reference: `/public/assets/aistudio/Frame_2_cfd366a1.png`).
- `sketchbook.png` - Open tilted notebook / sketchbook base
- `camera.png` - Instant Polaroid camera
- `music-player.png` - Mini cassette or streaming music player widget
- `pocket.png` - Denim pocket with pins, embroidery, and accessories
- `coffee.png` - Latte art coffee cup and stationery
- `binder-clips.png` - Brass metal binder clips

Supported formats: `.png` (with transparent background recommended), `.webp`, `.svg`, `.jpg`.
The portfolio website dynamically checks for and loads your uploaded files.
